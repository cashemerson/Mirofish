Capabilities

What MiroFish Does

A complete pipeline from raw documents to actionable predictions, powered by swarm intelligence and multi-agent simulation.

📊

Ontology Generation

Upload PDFs, markdown, or text files. The LLM extracts entity types, relationship types, and builds a structured ontology for your domain automatically.

🕸️

Knowledge Graph (GraphRAG)

Seed documents are chunked, embedded, and woven into a Zep knowledge graph with entities, relations, and collective memory for deep retrieval.

🤖

Multi-Agent Simulation

Spawn hundreds of LLM-driven agents with unique personas across simulated Twitter and Reddit platforms. Watch emergent behavior unfold in real time.

📝

Prediction Reports

A dedicated ReportAgent queries the post-simulation environment, synthesizes findings, and produces structured prediction reports with citations.

💬

Agent Interaction

Chat directly with simulated agents or the ReportAgent. Interview them about their reasoning, decisions, and the world they inhabited.

🎰

Sports & Event Intelligence

Purpose-built for sports betting and binary event trading. Probability-first modeling with EV calculation, Kelly sizing, and risk controls.

How it works

The Simulation Pipeline

From document upload to actionable prediction in five stages.

Step 1

Upload & Extract

Upload seed documents (PDF, MD, TXT). LLM generates an ontology of entity types and relationships.

Step 2

Build Graph

Documents are chunked and processed into a Zep knowledge graph with entities, edges, and memory.

Step 3

Spawn Agents

Agent profiles are generated from graph entities. Each gets a persona, memory, and behavior model.

Step 4

Run Simulation

Agents interact on simulated social platforms (Twitter + Reddit) for configurable rounds of activity.

Step 5

Generate Report

ReportAgent analyzes simulation output, produces a structured prediction report with confidence intervals.

Intelligence Module

Sports & Event Trading

Probability-first evaluation engine for sportsbooks and binary event contracts.

💰

EV Calculation

Automatic vig removal, fair probability extraction, and expected value computation across moneyline, spread, total, props, and Kalshi contracts.

📏

Kelly Sizing

Fractional Kelly staking (0.25x-0.50x) with hard caps per bet, game, day, and league. Correlation-aware position sizing.

🛡️

Risk Controls

Per-bet limits, daily drawdown circuit breakers, stale-data guardrails, slippage and liquidity abort conditions.

Market Input Schema

Every market evaluation follows the canonical input contract. Required fields ensure complete decision traceability.

Market_input_schema.json
{ "schema_version": "v1.0.0", "market": { "sport": "baseball", "league": "MLB", "market_type": "moneyline", "event": { home_team, away_team, venue, starts_at_utc }, "selection": { "side": "home" } }, "pricing": { "odds": { "american": -150, "decimal": 1.667, "implied_probability_raw": 0.60 } }, "model": { "predicted_probability": 0.65, "expected_value": { "ev_per_unit_stake": 0.083, "ev_after_costs": 0.071 } }, "risk": { "stake_recommendation": { "method": "fractional_kelly", "recommended_units": 1.5 } }, "execution": { "action": "place_bet" } }
